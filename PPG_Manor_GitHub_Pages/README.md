## 無料公開の手順
1. GitHubに ppgserver595-netizen でログイン。
2. 新しいリポジトリを作成。名前は ppgserver595-netizen.github.io、公開範囲は Public。
3. このZIPを解凍し、中の index.html / style.css / app.js / envelope.png / music-box.mp3 をリポジトリの一番上にアップロードして Commit changes。
   ZIPそのものや、ファイルを包んだフォルダをアップロードしないでください。
4. リポジトリの Settings → Pages → Build and deployment。
5. Source は Deploy from a branch、Branch は main、フォルダは / (root) を選び Save。
6. 公開処理完了後、Settings → Pages に表示される公開リンクを確認。

公開予定URL（公開完了するまではアクセスできません）:
https://ppgserver595-netizen.github.io/

ドメインの購入やChatGPTとの連携は不要です。
